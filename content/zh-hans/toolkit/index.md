# 工具箱

整理支持 AI 公司实际运转的工具与范例，并不意味着每家企业都需要使用全部工具。

| 工具 | 适用场景 |
| --- | --- |
| [FastFileLink / FFL MCP](https://github.com/nuwainfo/ffl-mcp) | 将大型 AI 成果交付给外部人员 |
| [MailTrigger](https://www.mailtrigger.net/) | 邮件事件路由与自动化 |
| [Wekan](https://wekan.github.io/) | 任务看板与协作 |
| [Memos](https://www.usememos.com/) | 笔记和工作记录 |
| [ERPNext](https://erpnext.com/) | 企业运营和审批 |

未来公布的脚本、角色配置与 MCP 示例会在此链接。
