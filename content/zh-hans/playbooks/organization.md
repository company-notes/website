# AI 组织与角色设计

企业使用 AI Bots，不应该只是创建大量角色。首先要明确：每个角色**有权做什么**、**必须交付什么**，以及**哪些操作需要人工批准**。

## 一份可实施的角色卡

| 字段 | 示例 |
| --- | --- |
| 角色 | 客户邮件助手 |
| 输入 | 已授权邮箱中的指定邮件 |
| 输出 | 分类后的需求、回复草稿 |
| 工具 | 有权限范围的 Mail / Task MCP |
| 禁止 | 自行确认报价或修改收款信息 |
| 验收 | 对外发送前由人工审核 |

!!! note "设计原则"
    权限必须由底层系统实施，不是只在 Prompt 中写一条禁止规则。

这是公开示例，不代表女娲内部所有 Bots 的实际配置。
