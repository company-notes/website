# 怎麼知道 Grok Bot 拿了我的帳號做了什麼？

現在 Grok Bot 真的很方便，尤其是增加了帳號密碼保險庫（Vault）功能之後。很多本來要我自己打開網頁、登入帳號、一步一步操作的事情，現在都可以請它幫忙。很多時候我只要出一張嘴，叫它去做，它就能幫我做好，省了非常多時間。

可是問題來了。

有時候它會卡住，有時候它會在網頁上亂點。那我怎麼知道它到底點了什麼？它跟我說事情做完了，可是它會不會順手刪掉我其他東西？或是不小心按錯了什麼，卻沒有跟我說？

現在 Grok Bot 還能透過 Vault 使用我授權的帳號去操作網站。這當然很方便，但要完全信任 AI，想想還是有點恐怖。

更麻煩的是，事後如果沒有紀錄，我根本不知道要怎麼追溯、怎麼還原。時間一久，搞不好連它自己都忘記做過什麼。

所以我就在想：**能不能讓 Grok Bot 每次操作網頁時，都把過程錄下來？**

於是我做了這個工具：[Agent Recorder MCP](https://github.com/company-notes/agent-recorder-mcp)。

讓 Grok Bot 裝好之後，它就能在操作瀏覽器之前啟動錄影，把自己操作網頁的畫面錄成 MP4。工作結束後，它會把影片與操作摘要 `summary.md` 一起打包成 ZIP，再透過 FastFileLink 把下載連結傳給我。一般環境會優先使用 P2P 傳輸；有些受限制的網路環境則會透過 relay。

影片和 ZIP 先放在 Agent 那台機器上，**等我確實下載完成，傳輸服務回報成功後，才自動刪除本機錄影與 ZIP**。這樣不用一直佔用它的空間。如果想留存，也可以選擇透過已連接的 Google Drive 上傳。

## 怎麼讓 Grok Bot 自己裝好？

我刻意把安裝方式弄得簡單一點，不用一般使用者自己研究一大堆 MCP 指令。

我做了一份 Skill，讓 Grok Bot 按照說明安裝、設定錄影工具，並知道什麼時候該開始、什麼時候該結束錄影。

你只需要把這個連結傳給 Grok Bot：

**[Agent Recorder Skill（最新版）](https://raw.githubusercontent.com/company-notes/agent-recorder-mcp/master/skills/agent-session-recording/SKILL.md)**

然後跟它說：

> 請閱讀並安裝這個 Skill，依照裡面的說明把錄影功能設定好。以後只要幫我操作瀏覽器，就先開始錄影，做完後提供含錄影和操作摘要的 ZIP 下載連結，並告訴我做了什麼。如果需要我授權或確認設定，請直接告訴我。完成後也請試錄一次，確認下載的 ZIP 裡有能正常播放的影片和摘要。

就這樣。它會依照自己環境支援的方式處理；需要你的授權時，再由你確認就好。如果目前的環境不支援錄影，它也應該直接告訴你，不能假裝已經裝好。

設定完成後，可以先叫它開個簡單的網頁試試，看看最後是不是真的拿得到包含影片和摘要的 ZIP。

## 以後請它做事，還要特別操作嗎？

不用，平常怎麼叫 Grok Bot 做事，就繼續怎麼用。

例如叫它登入網站、檢查設定或幫你完成一些本來得自己點來點去的工作。只要它依照 Skill 的規則執行，就會在開始操作瀏覽器之前先錄影，做完後再停止。

最後除了告訴你事情做得怎麼樣，它還會提供**錄影與操作摘要的 ZIP 下載連結**，以及簡短的工作回報。ZIP 裡有 MP4 和 `summary.md`，摘要會大致整理它做過哪些步驟、碰過哪些系統、出了什麼問題，以及怎麼處理。

想知道更細的過程，下載 ZIP、打開裡面的影片就能看。不用事後再跟它來回問：「你剛才到底按了哪個按鈕？」

## 錄影會不會一直佔空間？

預設不會一直留著。

影片先錄在 Agent 自己的機器上，與操作摘要打包成 ZIP 後透過 FastFileLink 分享；等 ZIP 下載完成後，才從那邊清除 MP4 和 ZIP。它不是把影片交給 AI 模型去看，也不是產生連結的瞬間就刪掉檔案。錄影檔也會依工作名稱和時間命名，比較好辨認。

你也可以選擇上傳到 Google Drive，方便自己留存。那會由 Agent 已連接的 Google Drive 工具負責上傳。

有一點要提醒：目前這套工具錄的是 **Agent 自己的 Linux X11 桌面**，不是你自己的 Windows 或 Mac 畫面。它也不是作業系統層級的強制稽核；Grok Bot 得真的按照 Skill 在操作前開始錄影，才會有完整的操作過程可看。

另外，錄影有可能拍到個人資料、後台畫面，甚至私鑰或驗證資訊。分享與保存時要自己注意，別把敏感影片公開。

## 用了之後，我真的安心很多

像後來我讓 Grok Bot 幫我處理申請 Apple 私鑰相關的事情，就放心很多。

它做好之後，會大概告訴我做了什麼，我還能去看錄影，知道它到底怎麼操作。如果哪裡怪怪的，我至少可以回頭查，而不是在那邊想：「它是不是刪掉了什麼？怎麼找不到了？」

當然，錄影不代表它不會犯錯，也不保證做錯的事都能還原。涉及私鑰和敏感帳號時，該確認的還是要確認。

但至少我不用只能聽它說「我做好了」，卻完全不知道過程發生什麼事。

我覺得這真的是每個會請 AI 幫忙操作網站的人，都應該有的功能。AI 幫我們省了很多時間，多一份錄影，就多一份安心。
